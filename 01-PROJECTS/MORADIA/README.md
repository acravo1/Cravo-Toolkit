# Recent Decisions

- O lago permanece no conceito.
- O regato permanece no conceito.
- A ponte permanece no conceito.
- O poço passa a ser considerado elemento central da composição paisagística.
- As árvores existentes deixam de condicionar o desenho futuro.
- As oliveiras jovens poderão ser transplantadas conforme necessário.
