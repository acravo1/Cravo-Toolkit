# Glossary

## Knowledge System

Sistema responsável por armazenar, estruturar e disponibilizar
conhecimento operacional do ecossistema Cravo.

Inclui:

- CTK
- Current State
- Documentação
- Fonte de Verdade (SSOT)

---

## SSOT (Single Source Of Truth)

Fonte principal dos dados.

Inicialmente:

workspace.xlsx

Potencialmente no futuro:

PostgreSQL + NocoDB

---

## Current State

Representação condensada do estado atual.

Responde:

- Onde estamos?
- O que mudou?
- O que falta?

Não substitui documentação.

Não substitui snapshots.

---

## Snapshot

Fotografia temporal do estado dos projetos.

Responde:

"O que existia numa determinada data?"

---

## Export

Extração completa do conteúdo dos repositórios.

Destinada a arquivo, auditoria e contexto detalhado.

---

## Memory

Conhecimento relevante acumulado ao longo do projeto.

Inclui:

- decisões
- descobertas
- riscos
- ideias

---

## Decision

Escolha arquitetural ou operacional considerada aceite.

Pode originar:

- PD
- ADR

---

## Project Context

Conjunto mínimo de informação necessária para retomar
um projeto rapidamente.

---

## Knowledge Hub

Visão futura do sistema composto por:

- Dados estruturados
- Documentação
- Current State
- CTK
- Home Assistant
- IA
