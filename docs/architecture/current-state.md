# Current State

## Objetivo

Gerar uma representação condensada do estado atual do ecossistema.

## Perguntas a responder

- Onde estamos?
- O que mudou recentemente?
- O que falta fazer?
- Quais os riscos atuais?
- Qual a próxima ação recomendada?

## Consumidores

- Utilizador
- CTK
- Home Assistant
- Assistentes IA

## Formatos previstos

- current-state.json
- current-state.md
- current-state.html

## Comando previsto

ctk push current-state

## Informação incluída

### Projetos

- Estado
- Fase
- Próximas tarefas

### Decisões recentes

- PDs
- ADRs
- Decisões operacionais

### Componentes

- Disponíveis
- Encomendados
- Em falta

### Infraestrutura

- Homelab
- Home Assistant
- VPN
- DDNS
